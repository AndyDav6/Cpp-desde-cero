## 01 - Tipos de datos

Los tipos de datos que hay en C++ son los tipos datos primitivos

- Enteros **(int)**:

```Cpp
#include <iostream>

int main() {
    int mi_numero_entero = 10;
}
```

- Flotantes **(float)**:

```cpp
#include <iostream>

int main() {
    float mi_numero_flotante = 11.25;
}
```

- Double:

```cpp
#include <iostream>

int main() {
    double mi_numero_fdouble = 11.255285582;
}
```

- Caracter **(char)**:

```cpp
#include <iostream>

int main() {
    char mi_caracter = 'A'
}
```
